# jxz345 Homebrew Tap

A [Homebrew](https://brew.sh) tap for [jxz345/Sleepless](https://github.com/jxz345/Sleepless), a fork of
[Aboudjem/Sleepless](https://github.com/Aboudjem/Sleepless) (this tap is forked from
[Aboudjem/homebrew-tap](https://github.com/Aboudjem/homebrew-tap)), and for [Mimo](https://github.com/jxz345/mimo) and the legacy
[Exit IP Monitor](https://github.com/jxz345/exit-ip-widget).

## Install

```sh
brew install --cask jxz345/tap/sleepless
```

Approve the first launch in **System Settings → Privacy & Security → Open Anyway** (the app is
ad-hoc signed), then run the one-time passwordless grant (bundled inside the app) so it can toggle
lid-close sleep without a password prompt:

```sh
/Applications/Sleepless.app/Contents/Resources/grant.sh
```

**Switching from the upstream cask?** Both install `/Applications/Sleepless.app` under the same
token, so remove the upstream one first:

```sh
brew uninstall --cask aboudjem/tap/sleepless
brew untap aboudjem/tap
```

## Uninstall

```sh
brew uninstall --cask jxz345/tap/sleepless         # quits the app, restores normal sleep
brew uninstall --zap --cask jxz345/tap/sleepless   # also removes the sudoers grant + prefs
```

## Exit IP Monitor

```sh
brew install --cask jxz345/tap/exit-ip-monitor
open /Applications/ExitIPMonitor.app
```

The app is ad-hoc signed (not notarized). Approve the first launch in **System Settings → Privacy &
Security → Open Anyway**. Close any "ExitIPMonitor" Not Opened dialog with **Done** before
approving it. After approval, verify that the installed app completed startup:

```sh
/bin/bash /Applications/ExitIPMonitor.app/Contents/Resources/diagnose-launch.sh --launch --timeout 60
```

The check verifies the signature, installed build, and a live main-thread heartbeat. A process
appearing in Activity Monitor alone is not success. If startup times out, it saves bounded
diagnostics under `~/Library/Application Support/ExitIPMonitor/Logs`; daemon setup logs are under
`/Library/Logs/ExitIPMonitor`. Quarantine and macOS security settings remain intact. See
[launch diagnostics](https://github.com/jxz345/exit-ip-widget#launch-diagnostics).

Installation is app-only. The optional Tailscale → Clash Verge provider is installed only
when you click **Install Provider** in the dashboard and complete administrator authentication.
Exit IP monitoring and saved profile editing work without it.

Uninstall first requests Quit, then verifies the app process is gone using targeted TERM/KILL
fallback, including pre-startup hangs. It unloads both provider services and removes their files
and existing removal grant. Cleanup failure stops removal. Reinstall performs the same cleanup,
then installs only the app; it never reinstalls the provider. Settings and logs are retained.

Homebrew keeps the old uninstall instructions for already-installed casks. Before the first
migration from an older build, run the new cleanup helper from an exit-ip-widget checkout, then
uninstall and reinstall. See [clean uninstall and reinstall](https://github.com/jxz345/exit-ip-widget#clean-uninstall-and-reinstall).
The inline cleanup block is generated by that project's `Scripts/sync-homebrew-cleanup.py`.
The published `v1.0` release now contains build **1.0 (8)**, built and published locally
without GitHub Actions. Startup and automatic refresh do not access Keychain; use
**Load saved profile** or **Load saved token** explicitly when needed.

The cask remains version `1.0`. After the old-hook migration above, use the following for
same-version replacements; `brew upgrade` does not detect a new build with the same version:

```sh
brew update
rm -f "$(brew --cache --cask jxz345/tap/exit-ip-monitor)"
brew reinstall --cask jxz345/tap/exit-ip-monitor
```

```sh
brew uninstall --cask jxz345/tap/exit-ip-monitor          # quits and removes the app
brew uninstall --zap --cask jxz345/tap/exit-ip-monitor    # also removes settings and logs
```

## Mimo 3.0

[Mimo](https://github.com/jxz345/mimo) supports Apple silicon Macs with macOS 14 or later,
with strict IPv4 and dual-stack proxy policies and exit-IP monitoring.

```sh
brew install --cask jxz345/tap/mimo
open /Applications/Mimo.app
```

Installation requests administrator authentication and installs Mimo's bundled, pinned Mihomo engine and daemons.
Direct releases Mimo's network controls; Rule and Global require a configured proxy and one fresh allowlisted IPv4 exit in both strict IPv4 and Dual-stack. There is no IPv6 allowlist.
Mimo's machine-wide services continue running when the GUI quits. See the [release notes](https://github.com/jxz345/mimo/releases/tag/v3.0-build.11)
for measured behavior and known protection limits. The app is ad-hoc signed, not notarized; the cask verifies its sealed signature before removing this app's quarantine.

Homebrew's version remains **3.0**; the app identifies **build 11**. To replace an earlier 3.0 build:

```sh
brew update
brew reinstall --cask jxz345/tap/mimo
```
The installed app is now **Mimo.app**. The legacy `jxz345/tap/exit-ip-monitor` cask must be uninstalled first because the services conflict.

Uninstall with `brew uninstall --cask jxz345/tap/mimo`. This removes Mimo-owned services, PF/boot policy, DNS controls, login registrations, generated profiles/caches and cleanup helpers, and restores networking. Saved settings, locally stored credentials and logs remain. No separate Mihomo formula is needed. Before deleting Mimo.app manually, use **Stop engine and use Direct** and wait for cleanup to complete. Homebrew uninstall also handles an app that has already been deleted.

Install, reinstall, upgrade and Activate restore every owned service, including an engine previously stopped. A conflicting engine requires confirmation before replacement; Tailscale is not stopped. Incoming TCP service replies remain available during outbound blocks. Build 11 improves blocked-session retry and event handling, preserves rejected IPv4 observations, compacts the dashboard and adds bounded log rotation/retention. General UDP-server behavior and physical sleep/wake retain their documented qualification limits.

Current app, service and archive names use Mimo. Existing settings and credentials migrate from the former identity. The standalone removal command is `sudo /Library/PrivilegedHelperTools/mimo-manage uninstall`. The dashboard also displays the Homebrew uninstall command. No separate `brew tap` step is needed.

## Casks

- **mimo**: IPv4/dual-stack proxy routing and exit-IP monitoring with a bundled, pinned engine.

- **sleepless** (`<upstream version>-jxz.<n>`): keep your Mac awake with the lid closed, on battery,
  with no external display. The fork adds a custom auto-off timer (1 min to 24 h), restores normal
  sleep when the app is quit or uninstalled, and steadies the menu-bar icon. See
  [jxz345/Sleepless](https://github.com/jxz345/Sleepless).
- **exit-ip-monitor**: a menu-bar app, desktop widget, and Control Center control showing your
  public exit IP address and country, with confirmed country-change alerts. See
  [jxz345/exit-ip-widget](https://github.com/jxz345/exit-ip-widget).
